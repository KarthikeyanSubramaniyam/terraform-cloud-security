## 📌 Executive Summary

**Category**: DevSecOps & Shift-Left Security  
**Tech Stack**: `Python 3.10+ · Terraform Plan JSON · Policy as Code · CI/CD Security`  

Static analysis security scanner inspecting Terraform plan JSON representations to block insecure cloud configurations prior to deployment.

---

## 🎯 The Problem It Solves

Fixing cloud misconfigurations in production is expensive and risky. Organizations need automated guardrails in CI/CD pipelines to catch vulnerabilities in infrastructure-as-code before resources are provisioned.

---

## ⚙️ How the Engine Works

1. **Terraform Plan Ingestion**: Parses JSON output generated by `terraform show -json <plan>`, extracting planned resource creations and modifications.
2. **Policy as Code Evaluation**: Evaluates proposed configurations against CIS benchmark policies and organizational baselines:
   - S3 buckets lacking server-side encryption or public access blocks
   - Security groups allowing `0.0.0.0/0` ingress to SSH (22) or RDP (3389)
   - RDS databases with `publicly_accessible = true`
   - Unencrypted EBS root volumes
3. **Violation Severity Scoring**: Categorizes findings into LOW, MEDIUM, and CRITICAL thresholds.
4. **CI/CD Integration**: Supports pipeline exit codes (`--fail-on-high`) to block PR merges and automated deployments when critical risks are detected.

---

## 🚀 Key Capabilities

- Pre-deployment infrastructure security validation
- Zero reliance on live cloud APIs (runs completely offline in CI/CD)
- Audits S3, EC2, RDS, IAM, and VPC Terraform resource blocks
- Configurable severity thresholds for automated build gating

## 📄 Findings Output Structure

The engine generates structured, machine-parsable JSON reports adhering to this standard audit schema:

```json
{
  "results": [
    {
      "resource": "resource-identifier",
      "severity": "HIGH",
      "check": "CHECK_IDENTIFIER",
      "detail": "Descriptive analysis of the identified security posture issue.",
      "remediation": "Actionable step-by-step guidance to restore compliant state.",
      "evidence": {
        "observed_field": "value",
        "required_policy": "enforced_policy"
      }
    }

  "count": 1,

```
